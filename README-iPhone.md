# RS Sultry-Royal iPhone App

This is a Progressive Web App (PWA) version of the RS Sultry-Royal appointment reminder.

## Put it online
The app must be hosted over HTTPS for iPhone Home Screen installation and service-worker features.

### Easiest route: GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. In GitHub: Settings → Pages → deploy from the main branch/root.
4. Open the resulting HTTPS address in Safari on your iPhone.

## Install on iPhone
In Safari:
1. Open the app's HTTPS address.
2. Tap Share.
3. Tap Add to Home Screen.
4. Confirm Add.

The app will then launch from the Home Screen in standalone mode.

## Important
Appointment data is stored in the browser's localStorage. It is not automatically synced between phones or browsers.
